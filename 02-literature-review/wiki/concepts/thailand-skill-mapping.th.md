## นิยาม
**Thailand Skill Mapping** คือฐานข้อมูลอ้างอิงทักษะระดับชาติที่เผยแพร่โดยสำนักงานปลัดกระทรวง
การอุดมศึกษา วิทยาศาสตร์ วิจัยและนวัตกรรม (สป.อว.) พัฒนาโดย สจล. ภายใต้การริเริ่มของ
ศ.ดร.สุรินทร์ คำฝอย เปิดสู่สาธารณะเมื่อกรกฎาคม 2568

โครงสร้าง (สแนปช็อต 2026-08-27, API `0.8.1-beta-public`)

| ระดับ | จำนวน | เนื้อหา |
|---|---|---|
| อุตสาหกรรม | 5 | การบินและโลจิสติกส์ หุ่นยนต์ ดิจิทัล ยานยนต์ไฟฟ้า อิเล็กทรอนิกส์อัจฉริยะ |
| อาชีพ | 371 (ดิจิทัล 138) | คำอธิบายภาษาไทย และเวกเตอร์อุปสงค์บนทักษะ |
| ทักษะ | 4,376 | ชื่อไทย + อังกฤษ นิยามไทย และประเภท `hard-skill` / `soft-skill` / `tools` |

ทุกทักษะมี **สามระดับความชำนาญ** — `ระดับพื้นฐาน` `ระดับปานกลาง` `ระดับสูง` — แต่ละระดับ
มีเกณฑ์ที่เขียนไว้ชัด 3–5 ข้อ และทุกคู่อาชีพ × ทักษะมี `count` ของอุปสงค์ `percentage`
และอัตรา `growth`

การเข้าถึง: API เปิดที่ `api.skillmapping.in.th` ไม่ต้องยืนยันตัวตน มีเว็บที่
[skillmapping.in.th](https://www.skillmapping.in.th/en),
[skill-mapping.ops.go.th](https://skill-mapping.ops.go.th/) และ
[skill.kmitl.ac.th](https://skill.kmitl.ac.th/)

## ลักษณะของข้อมูลที่จำกัดการใช้งาน
- `percentage` คือ **ความชุก** (สัดส่วนของประกาศงานของอาชีพนั้นที่เอ่ยถึงทักษะ)
  ไม่ใช่สัดส่วนของการแจกแจง ค่าของอาชีพหนึ่งรวมกันเกิน 100 ไปมาก
- เวกเตอร์อุปสงค์ **ถูกตัดปลายที่ราว 100 ทักษะต่ออาชีพ**
- จำนวนประกาศงาน `N` อยู่ระหว่าง 203 – 6,291,725 ซึ่งไม่น่าเป็นไปได้หากเป็นไทยอย่างเดียว
  ที่มาของคลังข้อมูลยังไม่ได้รับการยืนยัน
- 1.4% ของคู่อาชีพ × ทักษะมี `count = 0` และมีสามอาชีพดิจิทัลที่ข้อมูลไม่สมบูรณ์
- API ยังเป็นเบต้า การวิเคราะห์ต้องตรึงสแนปช็อต

## ความเกี่ยวข้องกับ Iris
นี่คือ **ฐานที่โครงการยืนอยู่ตอนนี้** มันให้สองครึ่งที่การออกแบบเดิมพยายามสร้างเองในฐานะ
ข้อมูลอ้างอิงระดับชาติ: คลังทักษะควบคุม (แทนแนวทางจัดกลุ่มที่เกิดขึ้นเอง) และอุปสงค์
ตลาดแรงงาน (แทน scraper เว็บหางาน)

แพลตฟอร์มนิยามจุดประสงค์ของตนเองว่าเป็นการเชื่อม *ฝั่งอุปสงค์* กับ *ฝั่งอุปทาน* —
สิ่งที่ตลาดต้องการ กับสิ่งที่หลักสูตรผลิต **แต่ที่เผยแพร่มีเพียงฝั่งอุปสงค์** Iris สร้างฝั่งอุปทาน
ซึ่งเป็นสิ่งที่ทำให้โครงการเป็นผลงานต่อโครงสร้างพื้นฐานระดับชาติ แทนที่จะเป็นเครื่องมือเดี่ยว ๆ

มันยังทำให้คำตอบเดิมของ [[q-thai-ontology]] เป็นโมฆะ: ตอนนี้คลังทักษะภาษาไทยที่ระดับ
ความละเอียดที่ Iris ต้องการมีอยู่แล้ว
