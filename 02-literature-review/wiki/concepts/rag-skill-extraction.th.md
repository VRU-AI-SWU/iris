## นิยาม
Retrieval-Augmented Generation (RAG) ที่ใช้กับการสกัดทักษะ: แทนที่จะให้ LLM สกัดทักษะ
จากข้อความแบบ zero-shot RAG จะค้นคืนนิยามทักษะที่เกี่ยวข้องจากฐานความรู้ก่อน (เช่น การจำแนก
ทักษะหรือทักษะที่สกัดมาก่อนหน้า) แล้วจึงสั่ง LLM ให้สกัดและปรับทักษะให้เป็นมาตรฐานในบริบทของ
ตัวอย่างที่ค้นคืนมา วิธีนี้ยึดการสกัดไว้กับคลังทักษะที่มีอยู่และลดการกุข้อมูล

## บทความที่กล่าวถึงเรื่องนี้
- [[xu-2025-llm-curricular-analytics]] — RAG ที่ยึดกับฐานทักษะชนะ zero-shot ในการสกัด
  รายวิชา → ทักษะ
- [[arslan-2026-turkish-skill-extraction]] — การค้นคืนด้วยเวกเตอร์ฝังตัวบวกการจัดอันดับใหม่
  ด้วย LLM เป็นค่าที่ดีที่สุดสำหรับภาษาทรัพยากรน้อย
- [[le-2026-competency-tagging-evidence]] — BM25 บวกการค้นคืนที่เสริมด้วยกราฟ แล้วให้ LLM
  เลือกแบบมีข้อจำกัดพร้อมช่วงข้อความหลักฐาน
- [[zhang-2024-job-market-entity-linking]] — การค้นคืนด้วย bi-encoder บนการจำแนก 13,890 รายการ
  โดย Acc@32 ราวสองเท่าของ Acc@1
- [[sarthi-2024-raptor]] — การค้นคืนเชิงลำดับชั้นสำหรับเอกสารยาว
- [[kavargyris-2025-escox-skill-extraction]] — LLM บวกเวกเตอร์ฝังตัวของการจำแนก บน ESCO

## ความเกี่ยวข้องกับ Iris
xu-2025-llm-curricular-analytics แสดงว่า RAG เป็นกลยุทธ์ที่ทำได้ดีที่สุดสำหรับการสกัดทักษะ
จากหลักสูตร การออกแบบเดิมของเราใช้การสกัดด้วย LLM แบบ zero-shot ข้อค้นพบนี้ชี้ว่าเราควร
พิจารณา RAG พร้อมฐานความรู้ทักษะที่โตขึ้น ในทางปฏิบัติ: เมื่อเราสกัดทักษะจากเอกสาร มคอ.
ชุดแรก ทักษะเหล่านั้นกลายเป็นคลังสำหรับค้นคืนในการสกัดครั้งถัดไป ทำให้ความสม่ำเสมอดีขึ้น
