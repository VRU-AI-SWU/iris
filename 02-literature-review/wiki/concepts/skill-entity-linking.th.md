## นิยาม
**การเชื่อมทักษะเชิงเอนทิตี** คืองานจับคู่ช่วงข้อความอิสระกับรายการในคลังทักษะควบคุมที่ตายตัว
มันต่างจาก *การสกัดทักษะ* ซึ่งให้สตริงผิวแบบคลังเปิด

| | การสกัดทักษะ | การเชื่อมทักษะเชิงเอนทิตี |
|---|---|---|
| ผลลัพธ์ | สตริงตามอำเภอใจ | รหัสในคลังที่ตายตัว |
| การประเมิน | ต้องปรับให้เป็นมาตรฐานก่อนจึงให้คะแนนได้ | ความแม่นยำ/ความครบถ้วนคำนวณได้ตรง |
| รูปแบบความล้มเหลว | คลังเลื่อนไหลและมีตัวเกือบซ้ำ | ลิงก์ที่พลาด ลิงก์ที่เกิน ความหมายผิด |
| ความสม่ำเสมอ | ต่างกันไปในแต่ละรอบ | เหมือนเดิมเมื่อใช้คลังเดียวกัน |

แนวทางสมัยใหม่ที่เป็นมาตรฐานคือค้นคืนก่อนแล้วค่อยตัดสิน: สร้างตัวเลือกจากคลัง (ด้วยเวกเตอร์
ฝังตัวเชิงหนาแน่น การจับคู่เชิงคำศัพท์ หรือทั้งคู่) แล้วให้แบบจำลองตัดสินว่าตัวเลือกใดใช้ได้จริง
เป็นงานเลือกที่มีข้อจำกัด ไม่ใช่การสร้างข้อความอิสระ

## บทความที่กล่าวถึงเรื่องนี้
- [[kavargyris-2025-escox-skill-extraction]] — สายงาน LLM + เวกเตอร์ฝังตัวของ ESCO
  เป็นงานที่ตีพิมพ์แล้วซึ่งใกล้สิ่งที่ Iris ทำที่สุด แต่ทำกับ ESCO แทนมาตรฐานไทย
- [[senger-2024-dl-skill-extraction-survey]] — สำรวจสาขา แนวทางที่เชื่อมกับ ESCO ครองสนาม
  และความไม่สอดคล้องของคำศัพท์ในการสกัดแบบเปิดเป็นปัญหาที่รู้กัน
- [[luyen-2025-skill-decomposition-ontology]] — การแตกย่อยด้วย LLM ให้สอดคล้องกับ
  ออนโทโลยีผู้เชี่ยวชาญ few-shot prompting ปิดช่องว่างความละเอียดระหว่างข้อความกับการจำแนก
- [[xu-2025-llm-curricular-analytics]] — RAG ที่ยึดกับฐานทักษะชนะ zero-shot ในการสกัด
  รายวิชา → ทักษะ และรับมือเอกสารรายวิชาที่สั้นหรือเป็นนามธรรมได้
- [[dixon-2023-occupational-models-42m]] — คลังที่จำกัด (775 ทักษะ) เพียงพอในระดับชาติ
  สนับสนุนความเป็นไปได้ของแนวทางคลังตายตัว
- [[zhang-2024-job-market-entity-linking]] — ⭐ งานเชื่อมทักษะระดับช่วงข้อความชิ้นแรก
  **BLINK Acc@1 23.55%, Acc@32 48.98%** บนทักษะ ESCO 13,890 รายการ
- [[arslan-2026-turkish-skill-extraction]] — สถาปัตยกรรมเดียวกันในภาษาทรัพยากรน้อยที่มี
  สัณฐานวิทยาซับซ้อน **0.56 ทั้งสาย** และการสกัดในภาษาต้นทางชนะการแปลเป็นอังกฤษ
- [[saroglou-2025-esco-eqf-linking]] — เทียบ Sentence Linking กับ Entity Linking
  ได้ EL Accuracy@1 **0.2881** และบริบทระดับประโยคช่วยได้
- [[le-2026-competency-tagging-evidence]] — ใช้ LLM เป็น *ตัวติดป้ายที่มีข้อจำกัดและผลิต
  หลักฐาน* micro-F1 0.57, MRR 0.82
- [[dong-2023-out-of-kb-mention-discovery]] — การสร้างแบบจำลอง NIL อย่างชัดแจ้งสำหรับ
  การกล่าวถึงที่ไม่มีรายการในคลัง
- [[herandi-2024-skill-llm]] — กิ่งที่ทำ fine-tuning สกัดอย่างเดียว ไม่มีการเชื่อม

## ความเกี่ยวข้องกับ Iris
ตอนนี้นี่คือ **งานวิจัยแกน** การเปลี่ยนทิศทางแปลงปัญหากลางของ Iris จาก "สกัดทักษะแล้วจัดกลุ่ม
เป็นคลัง" เป็น "เชื่อมคำอธิบายรายวิชาใน มคอ. ภาษาไทยกับคลังแห่งชาติ 4,376 รายการ" ซึ่งนิยาม
ได้ดีกว่า ประเมินเทียบกับการกำกับโดยผู้เชี่ยวชาญได้ตรง และทำซ้ำได้

มันยังแก้ข้อจำกัดของระยะที่ 3 ย้อนหลังด้วย การออกแบบเดิมเลือกการสกัดแบบ zero-shot เพราะ
RAG "ต้องมีคลังสำหรับค้นคืนซึ่งยังไม่มี" แต่นิยามทักษะ 4,376 รายการและเกณฑ์ระดับ 6,058 ข้อ
ของมาตรฐาน *คือ* คลังนั้น แนวทางที่ xu-2025 พบว่าดีกว่าจึงพร้อมใช้แล้ว

**สมรรถนะที่คาดหวังได้ จากงานวิจัยอิสระสามชิ้น** ความแม่นยำ top-1 แบบเข้มงวดสำหรับการเชื่อม
กับการจำแนกอาชีพขนาดใหญ่อยู่ราว **0.23–0.29** ([[zhang-2024-job-market-entity-linking]]
23.55%, [[saroglou-2025-esco-eqf-linking]] 0.2881) และคะแนนทั้งสายราว **0.56**
([[arslan-2026-turkish-skill-extraction]], [[le-2026-competency-tagging-evidence]]
micro-F1 0.57) ทุกชิ้นยังรายงานว่า *การจัดอันดับ* ดีกว่า *การเลือก* มาก — Acc@32
ราวสองเท่าของ Acc@1 และ MRR 0.82 เทียบกับ F1 0.57

มีข้อสรุปการออกแบบสองข้อที่ตามมา และทั้งคู่อยู่ในแผนของ Iris แล้ว: ค้นคืนอย่างใจกว้างแล้วตัดสิน
และ **วางหน้าจอตรวจโดยมนุษย์ไว้ระหว่างตัวเชื่อมกับข้ออ้างที่เผยแพร่** ที่ระดับความแม่นยำเช่นนี้
การจับคู่ที่ไม่ผ่านการตรวจไม่ใช่หลักฐาน
