## คำถามวิจัย
LLM สกัดทักษะจากเอกสารหลักสูตรได้น่าเชื่อถือแค่ไหนเมื่อเทียบกับวิธี NLP ดั้งเดิม
และกลยุทธ์ใดเหมาะกับเอกสารประเภทใด

## ข้อจำกัดของวิธีเดิม
งานก่อนหน้าสมมติว่า LLM ทำงานได้ดีในการสกัดทักษะจากหลักสูตรโดยไม่มีการประเมินเชิงประจักษ์
อย่างเป็นระบบ และไม่มีเกณฑ์เทียบสำหรับเปรียบเทียบแนวทางที่ใช้ LLM (RAG, zero-shot)
กับวิธี NLP ทั่วไปบนเอกสารหลักสูตรโดยเฉพาะ

## ผลงาน
การประเมินอย่างเป็นระบบของกลยุทธ์การจัดข้อความสี่แบบบนตัวอย่างแบ่งชั้นของเอกสารหลักสูตร
400 ฉบับ · กรอบการประเมินแบบมนุษย์ร่วมกับ LLM สำหรับการกำกับข้อมูล · และข้อเสนอที่มี
หลักฐานรองรับให้ใช้ RAG เป็นกลยุทธ์ที่ควรเลือก

## วิธีที่เสนอ
เทียบสี่กลยุทธ์: RAG · การสั่ง LLM แบบ zero-shot · การสั่ง LLM แบบ few-shot ·
และ NLP ทั่วไป (TF-IDF/การจับคู่คำสำคัญ) บนตัวอย่างแบ่งชั้นของเอกสารหลักสูตร 400 ฉบับ
ประเมินผ่านการกำกับข้อมูลร่วมกันระหว่างมนุษย์กับ LLM

## ข้อค้นพบสำคัญ
RAG เป็นกลยุทธ์ที่ทำได้ดีที่สุดกับเอกสารหลักสูตรทุกประเภท · การสั่งแบบ zero-shot ทำได้แย่กว่า
NLP ทั่วไปในกรณีส่วนใหญ่ · LLM รับมือคำอธิบายรายวิชาที่สั้นและเป็นนามธรรมได้ดีกว่าเอกสารที่ยาว
· และสมรรถนะต่างกันมากตามการเลือกแบบจำลองและวิธีการสั่ง ไม่มีค่าตั้งเดียวที่ใช้ได้ทุกกรณี

## ข้อจำกัดของบทความนี้
เป็นเอกสารหลักสูตรภาษาอังกฤษเท่านั้น · การประเมินร่วมกันระหว่างมนุษย์กับ LLM อาจมีอคติ
ในการกำกับข้อมูล · และสมรรถนะของ RAG ขึ้นกับคุณภาพของฐานความรู้ทักษะที่ใช้ค้นคืนอย่างมาก

## บันทึกสำหรับ Iris
ข้อค้นพบสำคัญ: RAG ทำได้ดีกว่า zero-shot ในการสกัดทักษะจากหลักสูตร นี่เป็นความท้าทาย
สำคัญต่อแนวทางของเรา เพราะการออกแบบปัจจุบันของเราใช้การสกัดด้วย LLM แบบ zero-shot
จากคำอธิบายรายวิชาใน มคอ. เราควรพิจารณา RAG พร้อมฐานความรู้ทักษะ (แม้จะเป็นฐานเล็ก ๆ
ที่เริ่มจากคลังที่เกิดขึ้นเองของเรา) ส่วนข้อค้นพบที่ว่า LLM รับมือเอกสารที่สั้นและเป็นนามธรรม
ได้ดีนั้นน่าอุ่นใจ เพราะคำอธิบายรายวิชาใน มคอ. จำนวนมากสั้น ส่วนการที่ zero-shot ทำได้แย่กว่า
เป็นความเสี่ยงที่ต้องติดธงไว้
