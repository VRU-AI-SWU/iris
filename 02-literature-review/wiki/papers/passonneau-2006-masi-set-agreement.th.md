## คำถามวิจัย
ควรวัดความสอดคล้องระหว่างผู้กำกับข้อมูลอย่างไร เมื่อผู้กำกับแต่ละคนกำหนด **เซต** ของป้ายให้
แต่ละหน่วย แทนที่จะเลือกหมวดเดียวจากรายการที่ตายตัว

## ข้อจำกัดของวิธีเดิม
ตัวชี้วัดความน่าเชื่อถือทั่วไป — Cohen's κ, Fleiss' κ, Scott's π — สมมติว่าแต่ละหน่วยได้ค่า
เชิงหมวดหมู่เพียงค่าเดียว เมื่อใช้กับการกำกับที่มีค่าเป็นเซต มันเทียบเซตด้วย **ความเหมือนกัน
ทุกประการ** ดังนั้น `{A, B}` เทียบ `{A, B, C}` จึงได้คะแนนว่าไม่ตรงกันเลย เหมือนกับ
`{A, B}` เทียบ `{X, Y}` ความสอดคล้องบางส่วนซึ่งเป็นกรณีปกติในการกำกับเชิงความหมาย
จึงมองไม่เห็น โครงการกำกับข้อมูลบนปรากฏการณ์เชิงความหมายหรือเชิงวัจนปฏิบัติที่ซับซ้อน
จึงรายงานความน่าเชื่อถือที่มีความหมายไม่ได้เลย

## ผลงาน
**MASI** ตัวชี้วัดระยะสำหรับเปรียบเทียบเซตที่จับความสอดคล้องบางส่วนได้ ใช้เป็นฟังก์ชันระยะ δ
ภายในสัมประสิทธิ์ความสอดคล้องแบบถ่วงน้ำหนักใดก็ได้ — Krippendorff's α หรือ β ของ
Artstein & Poesio โดยเป็นอิสระจากวิธีคำนวณความสอดคล้องที่คาดหวัง

## วิธีที่เสนอ

**MASI = J × M**

- **J** — สัมประสิทธิ์ Jaccard (1908) `|Q ∩ P| / |Q ∪ P|` ถ่วงความต่างของขนาดเซต
  โดยไม่ขึ้นกับความสัมพันธ์ของเซต
- **M** — พจน์ **monotonicity** ที่ลงโทษเซตที่ขัดแย้งกันมากกว่าเซตที่ซ้อนกัน

| ความสัมพันธ์ระหว่างเซต Q กับ P | M |
|---|---|
| เหมือนกัน | **1** |
| ตัวหนึ่งเป็นเซตย่อยของอีกตัว | **2/3** |
| มีส่วนร่วมและส่วนต่างทั้งสองไม่ว่าง | **1/3** |
| ไม่ทับกันเลย | **0** |

ใช้เป็น δ ใน Krippendorff's α บนผู้กำกับ *m* คนและหน่วย *r* หน่วย

```
α = 1 − ( (rm−1) Σᵢ Σ_b Σ_{c>b} n_b^i n_c^i δ_bc ) / ( m Σ_b Σ_c n_b n_c δ_bc )
```

## ข้อค้นพบสำคัญ
- พจน์ monotonicity แยกกรณีที่ตัวชี้วัดทั่วไปรวมเข้าด้วยกัน ในตัวอย่างที่บทความคำนวณให้ดู
  เมทริกซ์การกำกับที่มีความสัมพันธ์แบบเซตย่อยได้ค่า MASI เฉลี่ย **10/27 = 0.37**
  ขณะที่เมทริกซ์ที่มีส่วนต่างสมมาตรได้ **6/27 = 0.22** ซึ่งเป็นความแตกต่างที่ความสอดคล้อง
  แบบตรงทุกตัวแสดงไม่ได้เลย
- MASI เป็นอิสระจากการคำนวณความสอดคล้องที่คาดหวัง จึงประกอบเข้ากับสัมประสิทธิ์แบบถ่วงน้ำหนัก
  ใดก็ได้ โดยไม่ต้องสร้างสัมประสิทธิ์ใหม่
- Artstein และ Poesio (2548) พบว่าความต่างเชิงปริมาณระหว่างตระกูลของตัวชี้วัดโดยทั่วไปเล็ก —
  ทางเลือกที่สำคัญที่นี่คือ **ฟังก์ชันระยะ** ไม่ใช่ตัวสัมประสิทธิ์

## ข้อจำกัดของบทความนี้
สาธิตบนการกำกับ co-reference และ summarisation pyramid ไม่ใช่บนการเชื่อมเอนทิตีกับ
คลังคำศัพท์ควบคุมขนาดใหญ่ · และ MASI ไม่มีแนวคิดของระยะ *เชิงความหมาย* ระหว่างป้าย —
`{SQL}` เทียบ `{MySQL}` ห่างเท่ากับ `{SQL}` เทียบ `{จริยธรรม}` ซึ่งทำให้ความสอดคล้อง
ต่ำกว่าจริงเมื่อผู้กำกับเลือกรายการที่เกือบพ้องกันจากการจำแนกที่ละเอียด

## บันทึกสำหรับ Iris
**บทความนี้แก้ความผิดพลาดในแผนการประเมินของ Sprint 4 ที่จะให้ตัวเลขที่ผิด**

แผนผูกพันกับผู้กำกับสองคนและการรายงานความสอดคล้อง และตามคำแนะนำของ
[[zhang-2024-job-market-entity-linking]] ผูกพันกับการอนุญาตให้มี **การเชื่อมที่ถูกต้อง
หลายรายการต่อวิชา** นั่นทำให้งานกำกับข้อมูลของ Iris มีค่าเป็นเซตโดยโครงสร้าง: ผู้กำกับแต่ละคน
กำหนด *เซต* ของรหัสทักษะแห่งชาติให้แต่ละรายวิชา ไม่มีอะไรในแผนระบุว่าจะใช้สถิติความสอดคล้อง
ตัวใด และทางเลือกปริยายคงเป็น κ ของ Cohen หรือ Fleiss

บนงานนี้ทั้งสองผิดล้วน ๆ ผู้กำกับสองคนที่คืน `{SQL, Data Modeling}` กับ
`{SQL, Data Modeling, Database Design}` สำหรับ คพ242 เห็นตรงกันเป็นส่วนใหญ่ แต่ κ
แบบตรงทุกตัวให้คะแนนว่าไม่ตรงกันเลย เนื่องจากความสัมพันธ์แบบเซตย่อยคือรูปแบบความไม่ตรงกัน
ที่ *คาดหวังได้* ระหว่างผู้กำกับที่เข้มงวดกับผู้ที่ผ่อนปรน κ จึงทำให้ความสอดคล้องต่ำกว่าจริง
อย่างเป็นระบบ และค่า IAA ที่ต่ำก็จะทำลายความน่าเชื่อถือของการประเมินที่ที่จริงแล้วสมเหตุสมผล

**รับมาใช้กับการกำกับชุดทักษะ:** Krippendorff's α กับระยะ MASI พจน์ monotonicity เป็น
คุณสมบัติที่สำคัญ — มันแยก *"ผู้กำกับคนหนึ่งใจกว้างกว่า"* (M = 2/3) ออกจาก *"ผู้กำกับไม่เห็น
ตรงกันว่ารายวิชานี้สอนอะไร"* (M = 1/3 หรือ 0) ซึ่งเป็นความแตกต่างที่คู่มือการกำกับข้อมูล
ต้องปรับให้เข้ากันพอดี

⚠️ **ไม่ใช้กับการกำหนดระดับ** ระดับเป็นค่า **ลำดับ** ค่าเดียวต่อคู่ (รายวิชา, ทักษะ) —
`พื้นฐาน < ปานกลาง < สูง` — ไม่ใช่เซต MASI จะให้คะแนน *พื้นฐานเทียบปานกลาง* ห่างเท่ากับ
*พื้นฐานเทียบสูง* พอดี ซึ่งทิ้งลำดับที่เป็นเนื้อหาทั้งหมดของระดับไป ความสอดคล้องของระดับ
จึงใช้ Krippendorff's α กับระยะแบบ **ลำดับ** เพื่อให้ความไม่ตรงกันของระดับที่อยู่ติดกัน
นับเป็นความสอดคล้องบางส่วน บทเรียนทั่วไปคือการเลือก δ ตามชนิดข้อมูล ส่วน MASI เป็นคำตอบ
ที่ถูกต้องเฉพาะครึ่งที่มีค่าเป็นเซต

ข้อจำกัดที่ระบุไว้ใช้กับ Iris จริงและควรรายงาน: MASI ถือว่า
`การสร้างแบบจำลองข้อมูลเชิงสัมพันธ์` กับ `การสร้างแบบจำลองข้อมูลเชิงตรรกะ` ต่างกันโดยสิ้นเชิง
ความสอดคล้องบนคลังที่ละเอียดจึงถูกวัดแบบอนุรักษ์นิยม รุ่นที่ถ่วงน้ำหนักเชิงความหมายอยู่นอก
ขอบเขตของรุ่นแรก แต่ควรระบุไว้ในข้อจำกัด
