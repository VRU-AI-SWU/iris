## คำถามวิจัย
ระบบ NLP เฉพาะสาขาจะสกัดทักษะ CS/IT จากเนื้อหารายวิชาและประกาศงานเพื่อสนับสนุนการแนะนำ
รายวิชาและการออกแบบหลักสูตรในมหาวิทยาลัยเทคโนโลยีได้อย่างไร

## ข้อจำกัดของวิธีเดิม
แบบจำลอง NER สำหรับการสกัดทักษะ CS/IT ก่อนหน้าเป็นแบบทั่วไป (ไม่ได้ฝึกบนคลัง CS/IT)
หรือใช้แบบจำลองที่อิง CRF แบบตื้นโดยไม่มีเวกเตอร์ฝังตัวเชิงบริบท · ระบบแนะนำรายวิชาที่มีอยู่
พึ่ง collaborative filtering หรือความคล้ายของคำอย่างง่าย ไม่ใช่การจับคู่เชิงความหมายระดับทักษะ ·
และไม่มีระบบครบวงจรที่เชื่อมเนื้อหารายวิชาของมหาวิทยาลัยกับความต้องการของงานในระดับความละเอียด
ของทักษะ

## ผลงาน
(1) **CSIT-NER** — แบบจำลองการรู้จำเอนทิตีชื่อเฉพาะสาขาสำหรับทักษะ CS/IT ปรับบนข้อความ
จาก StackOverflow และ GitHub ด้วยเวกเตอร์ฝังตัว BERTOverflow ทำได้ดีกว่าค่าฐาน NER
ทั่วไปในทุกตัวชี้วัด (2) **CSIT-CRS แบบผสม** — ระบบแนะนำรายวิชาที่ใช้การสกัดทักษะของ
CSIT-NER ให้ข้อเสนอแนะหลายระดับ (รายวิชาของมหาวิทยาลัย เส้นทางอาชีพ และ MOOC ออนไลน์)
ประเมินกับผู้ใช้ 201 คน (นักศึกษาและอาจารย์ในออสเตรเลียและเวียดนาม)

## วิธีที่เสนอ
- **CSIT-NER:** เวกเตอร์ฝังตัว BERTOverflow (BERT ที่ฝึกล่วงหน้าบนข้อมูล StackOverflow)
  + BiLSTM + ชั้น CRF ฝึกและปรับบนข้อความ CS/IT จาก StackOverflow และ GitHub
  ประเภทเอนทิตี: ภาษาโปรแกรม เฟรมเวิร์ก เครื่องมือ และแนวคิด
- **CSIT-CRS:** การแนะนำแบบผสม — (ก) วิเคราะห์ช่องว่างทักษะระหว่างโปรไฟล์นักศึกษากับ
  ความต้องการของเส้นทางอาชีพ (ข) จับคู่ความคล้ายรายวิชา–ทักษะ (ค) แนะนำ MOOC สำหรับช่องว่างทักษะ
- **ข้อมูล:** StackOverflow + GitHub สำหรับการฝึก NER และประกาศงานจากบริษัท CS/IT จริง
  สำหรับความต้องการทักษะของเส้นทางอาชีพ
- **การประเมิน:** ตัวชี้วัด NER มาตรฐาน (ความแม่นยำ ความครบถ้วน F1) เทียบค่าฐาน BERTOverflow
  และแบบสำรวจผู้ใช้ (201 คน ออสเตรเลีย + เวียดนาม)

## ข้อค้นพบสำคัญ
- CSIT-NER ทำได้ดีกว่าแบบจำลอง NER ระดับ SOTA (รวมถึง BERTOverflow) ในการสกัดทักษะ CS/IT
  ในทุกตัวชี้วัดการประเมิน
- การถ่ายโอนการเรียนรู้จากคลังเฉพาะสาขา (StackOverflow/GitHub) ปรับปรุงความแม่นยำของ
  การรู้จำเอนทิตีทักษะได้อย่างมากเมื่อเทียบกับ BERT ทั่วไป
- การแนะนำแบบผสมที่อิงทักษะได้รับคะแนนสูงจากนักศึกษาในด้านความเกี่ยวข้องและประโยชน์
  ต่อการวางแผนหลักสูตร
- คลังคำศัพท์ทักษะ CS/IT จาก StackOverflow/GitHub เป็นภาษาอังกฤษและเฉพาะกับ tech stack มาก
  ครอบคลุมทักษะการเขียนโปรแกรมได้ดี แต่อ่อนกับทักษะทางสังคมและการบริหาร

## ข้อจำกัดของบทความนี้
คลังฝึก (StackOverflow + GitHub) เป็นภาษาอังกฤษทั้งหมด สมรรถนะบนข้อความเทคนิคสองภาษา
(ไทย+อังกฤษ) ยังไม่ได้ทดสอบ · ข้อมูล StackOverflow เอนไปทางโอเพนซอร์ส/การพัฒนาเว็บ
อาจทำได้ไม่ดีกับบทบาทในองค์กรหรือบทบาทที่ไม่ใช่การเขียนโค้ด · ระบบแนะนำรายวิชาสมมติว่ามี
การจับคู่รายวิชา–ทักษะที่ตายตัว ไม่ได้สกัดทักษะจากประมวลรายวิชาแบบพลวัต · และการประเมิน
เป็นแบบสำรวจความพึงพอใจ ไม่ใช่การทดลองที่มีการควบคุม

## บันทึกสำหรับ Iris
**ผลต่อการออกแบบของ Iris สองข้อ**

1. **เวกเตอร์ฝังตัวเฉพาะสาขาสำหรับ NER ทักษะ:** ผลของ CSIT-NER ยืนยันว่าแบบจำลองแบบ
   BERTOverflow (ฝึกล่วงหน้าบนข้อความในสาขา) ทำได้ดีกว่า BERT ทั่วไปอย่างมีนัยสำหรับ
   การสกัดทักษะ CS/IT สำหรับ Iris นั่นแปลว่าการสกัดทักษะจากประมวลรายวิชา มคอ. ของเรา
   (ซึ่งมีคำศัพท์ CS ทั้งไทยและอังกฤษ) ควรใช้แบบจำลองที่รู้จักสาขา CS/IT อยู่บ้าง —
   ไม่ BERTOverflow สำหรับช่วงภาษาอังกฤษ ก็ตัวเทียบเท่าที่เป็นหลายภาษา ส่วนทำเนียบภาษาไทย
   เชิงวิชาการเป็นความท้าทายที่ CSIT-NER ไม่ได้แตะ
2. **ผลลัพธ์ช่องว่างหลายระดับ:** สถาปัตยกรรม CSIT-CRS (วิเคราะห์ช่องว่าง → จับคู่รายวิชา →
   เติมช่องว่างด้วย MOOC) มีโครงสร้างคล้ายระบบสถานการณ์สามชั้นในการระดมความคิดของเรา
   เป็นการยืนยันว่าสายงานแบบวิเคราะห์ช่องว่างแล้วแนะนำเป็นรูปแบบที่พิสูจน์แล้วในวรรณกรรม
