## คำถาม

## ทำไมเรื่องนี้สำคัญต่อ Iris
การจำแนกกำหนดว่าทักษะถูกตั้งชื่อ จัดกลุ่ม และเปรียบเทียบอย่างไร และยังกำหนดว่าผลลัพธ์
ทำซ้ำได้หรือไม่ และเทียบกับงานของคนอื่นได้หรือไม่

## บทความที่เกี่ยวข้อง
- [[thailand-skill-mapping]] — ⭐ คลังที่รับมาใช้: 4,376 ทักษะภาษาไทยพร้อมนิยามและสามระดับ
  มีสถานะเป็นมาตรฐานแห่งชาติอย่างเป็นทางการ
- [[dixon-2023-occupational-models-42m]] — คลังที่จำกัด 775 ทักษะเพียงพอในระดับชาติของสหรัฐ
  สนับสนุนความเป็นไปได้ของคลังคงที่ และ 4,376 อยู่เหนือกว่านั้นอย่างสบาย
- [[kavargyris-2025-escox-skill-extraction]] — สายงานเชื่อมด้วย LLM + เวกเตอร์ฝังตัวของการจำแนก
  บน ESCO เป็นแม่แบบเชิงระเบียบวิธีโดยตรง
- [[xu-2025-llm-curricular-analytics]] — RAG ที่ยึดกับฐานทักษะชนะ zero-shot ในงานรายวิชา → ทักษะ
  และนิยามของมาตรฐานให้ฐานนั้น
- [[senger-2024-dl-skill-extraction-survey]] — การจำแนกที่ตายตัวพลาดทักษะที่เกิดใหม่และเฉพาะสาขา
  เป็นต้นทุนที่รับไว้ตรงนี้ ติดตามใน [[q-out-of-vocabulary]]
- [[sabet-2024-course-skill-atlas]] — ใช้ O*NET DWA ที่ตายตัวกับประมวลรายวิชาในระดับชาติ
  เป็นงานที่มีมาก่อนซึ่งใกล้ที่สุดสำหรับฝั่งหลักสูตร
- [[luyen-2025-skill-decomposition-ontology]] — การแตกย่อยแบบ few-shot เพื่อปิดช่องว่าง
  ระดับความละเอียดระหว่างข้อความกับการจำแนก
- [[vo-2022-nlp-curriculum-learning-path]] — NER ที่ปรับเฉพาะสาขาสำหรับข้อความหลักสูตร CS/IT
  เป็นอีกเส้นทางหนึ่งของการสร้างตัวเลือก
- **[[zhang-2024-job-market-entity-linking]]** — ⭐ **เพิ่ม 2026-08-28** งานเชื่อมทักษะระดับ
  ช่วงข้อความชิ้นแรก วางความคาดหวังด้านสมรรถนะของวงการไว้ที่ Acc@1 23.55% บนทักษะ ESCO 13,890 รายการ
- **[[arslan-2026-turkish-skill-extraction]]** — ภาษาทรัพยากรน้อยที่ไม่มีการจำแนกของตัวเอง
  จึงต้องยืม ESCO มา เป็นตำแหน่งที่ภาษาไทยอยู่ก่อนมีมาตรฐานแห่งชาติ
- [[saroglou-2025-esco-eqf-linking]] — บริบทระดับประโยคช่วยการเชื่อม และตัวจัดอันดับแบบมีผู้สอน
  ชนะ LLM แบบ decoder-only ได้
- [[dong-2023-out-of-kb-mention-discovery]] — วิธีจัดการสิ่งที่คลังคงที่พลาดไป
- [[herandi-2024-skill-llm]] — ทางเลือกแบบ fine-tuning ที่ไม่ได้รับมาใช้ (ไม่มีข้อมูลไทยที่กำกับแล้ว)

## คำตอบที่ใช้อยู่
สถานะ: **ตอบแล้ว — มาตรฐานแห่งชาติ ตรึงด้วยสแนปช็อต**

Iris รับ **Thailand Skill Mapping** เป็นคลังคำศัพท์ควบคุม งานจึงกลายเป็น
[[skill-entity-linking]] แทนที่จะเป็นการสกัดแบบเปิดบวกการจัดกลุ่ม

สิ่งที่ได้มา

| | คลังที่เกิดขึ้นเอง | มาตรฐานแห่งชาติ |
|---|---|---|
| ความเสถียรข้ามรอบ | ไม่แน่นอน | คงที่ |
| มาตรฐานทองสำหรับการประเมิน | ไม่มี | การกำกับข้อมูลนิยามได้ชัด |
| การเทียบกับงานอื่น | ไม่ได้ | ได้กับใครก็ตามที่ใช้มาตรฐาน |
| การทำซ้ำ | แย่ | สแนปช็อตที่ตรึงไว้ |
| การจัดระดับความชำนาญ | ไม่มี | สามระดับพร้อมเกณฑ์ |
| สถานะอย่างเป็นทางการ | ไม่มี | ข้อมูลอ้างอิงของ สป.อว. |

สิ่งที่แลกไป — ความครอบคลุมของทักษะที่อยู่นอกคลัง — ถูกรับไว้อย่างรู้ตัวและติดตามใน
[[q-out-of-vocabulary]] ส่วนการจับคู่กับ ESCO ถูกตัดออก เพราะมันเป็นตัวแทนของความเปรียบเทียบได้
ที่มาตรฐานแห่งชาติให้โดยตรงอยู่แล้ว และการแปลเนื้อหาหลักสูตรไทยเข้าสู่การจำแนกภาษาอังกฤษ
ของยุโรปจะเพิ่มสัญญาณรบกวนโดยไม่ได้อะไร

## ความไม่แน่นอนที่เหลืออยู่
- ความครอบคลุมเนื้อหา CS เชิงวิชาการ — [[q-out-of-vocabulary]]
- ความลึกของการค้นคืน `k` สำหรับการสร้างตัวเลือก และสมดุลระหว่างเชิงหนาแน่นกับเชิงคำศัพท์
- นโยบายการรีเฟรชสแนปช็อตเมื่อมาตรฐานเปลี่ยนไป
- พื้นที่ตัวเลือกที่เล็กกว่าของ Iris (4,376 เทียบกับ 13,890 ของ ESCO) และข้อมูลเข้าที่สมบูรณ์กว่า
  (คำอธิบายรายวิชาทั้งชิ้นแทนช่วงข้อความจากประกาศงาน) ให้ความแม่นยำดีกว่า 0.23–0.29
  ที่วรรณกรรมรายงานจริงหรือไม่ มีเหตุให้คาดหวัง แต่ผลลัพธ์ต้องไม่นำเสนอว่าเทียบกันได้โดยตรง
- ตัวจัดอันดับแบบมีผู้สอนชนะการตัดสินด้วย LLM หรือไม่ อย่างที่
  [[saroglou-2025-esco-eqf-linking]] พบในขั้นตอนของพวกเขา — ให้รวมไว้ใน ablation ของ Sprint 4
